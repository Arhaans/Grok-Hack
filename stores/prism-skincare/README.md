# Prism Skincare

The demo merchant storefront for **Prism**: a React + Vite skincare shop that has Prism installed
(`<script src="/prism.js">` in `index.html`). Built into the Prism app at `/store/` with `pnpm store:build`;
`/store/?clone=1` renders the copycat outlet from the data it scraped.

```bash
npm install
npm run dev   # standalone on :5175, proxies /api to the Prism app on :3100
```
